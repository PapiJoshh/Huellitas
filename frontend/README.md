# Frontend · Huellita Perdida

Aplicación de página única con React 19, Vite 8 y Tailwind CSS.

```bash
npm install
npm run dev      # http://localhost:5173/Huellitas/
npm run build    # genera dist/
npm run lint
```

Copia `.env.example` a `.env` y define `VITE_API_URL` con la URL de la API. La guía completa está en el [README principal](../README.md).
